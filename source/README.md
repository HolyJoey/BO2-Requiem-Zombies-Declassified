# DLC5 script sources (reference only)

The 47 loose scripts from Zombies Declassified 2.0.5 (Logo2K, with Fr0sty's patches), exactly as shipped.
v2 compiles them with gsc-tool and stores them inside `t6game/mods/dlc5/mod.ff`.
**Don't copy these into your game folder:** they would load a second time next to the ones in `mod.ff`.

`scripts/zm/zzz_protoround.gsc` and `scripts/zm/zzz_zm_roundfix.gsc` were already compiled in 2.0.5; they are
included as-is.
